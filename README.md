# INDUSTRIAI Dashboard Demo

ต้นแบบเว็บสำหรับสาธิตด้วยข้อมูลจำลอง ไม่มีการเชื่อมต่อเซนเซอร์ ส่ง LINE หรืออ้างลูกค้าจริง

## เปิดใช้งาน

เปิด `index.html` ด้วย Chrome หรือ Edge ได้โดยตรง ไม่ต้องติดตั้งแพ็กเกจ ไม่ใช้ API key และไม่ต้องเชื่อมอินเทอร์เน็ต

## ลำดับสาธิต

1. กด **เริ่มสาธิตใหม่** เพื่อกลับสู่ข้อมูลพื้นฐานและล้างประวัติใน Demo
2. กด **จำลองเหตุผิดปกติ** เครื่อง M-03 จะมีอุณหภูมิ 85°C และการสั่น 5.8 mm/s
3. เปิด **ตัวอย่าง LINE** เพื่อดูข้อความแจ้งเตือนจำลอง แล้วกดดูรายละเอียดเครื่อง
4. กด **รับทราบ** เลือกสถานะงาน และพิมพ์ `กำลังตรวจสอบระบบระบายความร้อน`
5. เปิด **รายงานและบันทึก** เพื่อดูผล และดาวน์โหลด CSV ได้

ค่าของเครื่อง M-01, M-02 และ M-03 รวมถึงเกณฑ์ 60/80°C และ 3/5 mm/s เป็นตัวอย่างเท่านั้น ไม่ใช่ค่ามาตรฐานการใช้งานจริง

ประวัติถูกเก็บใน localStorage เฉพาะเบราว์เซอร์ ไม่ได้ซิงก์ข้ามเครื่องหรือผู้ใช้ การปิดงานไม่แปลว่าอุณหภูมิจะลดลงโดยอัตโนมัติ ใช้ปุ่มเริ่มสาธิตใหม่เพื่อกลับสู่ข้อมูลเริ่มต้น

ทุกหน้ามีข้อความกำกับว่าเป็นข้อมูลจำลอง ส่วน LINE เป็นภาพหน้าจอที่สร้างด้วย HTML เพื่ออธิบายแนวคิดเท่านั้น
